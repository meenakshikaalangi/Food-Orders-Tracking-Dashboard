# Food-Orders-Tracking-Dashboard
My first Power BI project – a dashboard to track and visualize food orders for MealDash.

## 📘 Overview
This is my **first Power BI project**, created to analyze and visualize food order data for a fictional company called **MealDash**.  
The dashboard provides insights into customer demographics, order behavior, and meal preferences to help the company make **data-driven business decisions**.

## 🎯 Objective
To design an interactive and insightful **Food Orders Tracking Dashboard** that helps understand:
- How customers order food across different platforms  
- Which meal types are most popular  
- Demographic and behavioral patterns among customers  

## 🧠 Key Insights
- **Total Orders:** 7,859  
- **Average Food Rating:** 4.0  
- **Average Order Value:** 764  
- **Average Customer Age:** 25  
- **Most Preferred Platform:** Swiggy/Zomato/EatClub (91.79%)  
- **Most Preferred Meal Type:** Lunch (62.96%)  
- **Top Customer Group:** Students (53.7%)

## 🧩 Dashboard Features
- KPIs for key metrics (Orders, Ratings, Age, Value, etc.)  
- Donut charts for **Platform**, **Meal Type**, and **Gender Split**  
- Visuals showing customer **Marital Status**, **Education**, **Occupation**, and **Income**  
- Interactive **City filter** for regional analysis

## ⚙️ Tools & Technologies
- **Power BI** – For dashboard design and visualization  
- **Power Query** – For data cleaning and transformation  
- **Excel/CSV** – As the data source  

## 📊 Project Purpose
To demonstrate how **data visualization** helps food delivery businesses identify:
- Popular ordering platforms  
- Key customer demographics  
- Potential areas for marketing and service improvement
